เข้าสู่ระบบผู้ดูแลระบบ

คู่มือการใช้งานระบบงานวัดและประเมินผล

1

การเลือกเข้าใช้งานระบบสารสนเทศย่อย

ท่านสามารถคลิกเลือกเมนูแท็บระบบต่าง ๆ ทาง ด้านซ้ายมือ ของหน้าจอ ระบบจะเปิดหน้าต่างใช้งานภายในเว็บไซต์ทันทีโดยไม่ต้องเปิดแท็บใหม่

2

การดาวน์โหลดเอกสารและไฟล์แนบ

ในส่วนของ ข่าวประชาสัมพันธ์ หน้าแรก สามารถคลิกปุ่มไฟล์แนบ (ไฟล์ 1, ไฟล์ 2, ไฟล์ 3) เพื่อดาวน์โหลดแบบฟอร์มหรือเอกสารวัดผลการเรียนได้ทันที

3

การสลับโหมดมืด (Dark Mode) และสว่าง

คลิกปุ่มรูปดวงจันทร์/ดวงอาทิตย์ มุมบนขวาของเว็บไซต์ เพื่อเปลี่ยนเป็นโหมดมืดหรือสว่างตามสายตาและความสะดวกในการใช้งาน

4

การเชื่อมต่อกับ Google Sheet Database

แอดมินสามารถนำ Web App URL ที่ได้จาก Google Apps Script มาใส่ในระบบ เพื่อจัดเก็บข้อมูลทั้งหมดลงบน Google Sheets แบบออนไลน์ได้ทันที

เอกสารแนบดาวน์โหลด (สูงสุด 3 ไฟล์)
รูปภาพประกอบ (ใส่ได้หลายรูปภาพ)

จัดการแท็บระบบย่อย (สลับลำดับ / เพิ่ม / แก้ไข / ลบ)

เพิ่มแท็บระบบใหม่

ลำดับระบบย่อยปัจจุบัน (กดปุ่มสลับขึ้น-ลงได้ทันที)

ลำดับ ชื่อระบบ URL สลับลำดับ จัดการ

การทำงานแบบ Realtime Auto-Sync
